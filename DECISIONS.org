* Proposed Title
Catalist: A Menu-Driven Anime and Manga Tracker

* Abstract
Catalist is a menu-driven C++23 console application for keeping track of anime and manga. Through numbered menus, a person can add, view, update and remove titles, see statistics, and undo a mistake. The lists are saved in one CSV file beside the program. New titles are found through AniList's public API without an account, and lists can be moved in and out as MyAnimeList XML.

* Introduction
People who follow anime and manga often track dozens or hundreds of titles at once. Catalist keeps those lists in a simple console program, where the most common action, recording one more episode or chapter, takes a few number keys.

* Background of the Program
Catalist is the final project for CC 202 Computer Programming 1, which calls for a complete C++ console application with CRUD operations, decision statements, loops, input validation and a user-friendly menu with an Exit option.

* Problem
Tracking sites need a browser, an account and a connection for every small update. A list kept in a text file or spreadsheet has none of those costs, but it does not know episode totals, cannot undo a mistake, and makes statistics manual work.

* Current Solution
AniList and MyAnimeList are the main tracking websites. Both keep a person's list on their servers and require an account to track titles.

* Proposed Solution
Catalist keeps the list in a readable CSV file on the person's computer and goes online only to add a title.
- Every action is a numbered menu choice.
- Titles are found by any part of their name.
- Changes can be undone while the program is running.
- No account is needed.
- Lists can move to and from AniList and MyAnimeList through XML.

* Objectives
This console application aims to make tracking anime and manga simple and private.

Specifically:
1. To develop a menu-driven C++ console application that performs create, read, update and delete operations on anime and manga lists.
2. To implement status and date rules that keep each title's record consistent.
3. To validate all input and handle errors without losing data.
4. To be able to find titles through AniList and exchange lists through MyAnimeList XML.

* Scope and Limitations
*Scope:* anime and manga lists, progress, scores, statuses, dates, statistics, AniList search, MyAnimeList XML import and export, and undo within a run.

*Limitations:*
- It runs on Linux and is built with GCC.
- Adding a title needs an internet connection and the =curl= program.
- It does not sync with accounts on any site.
- Episode totals are not refreshed after a title is added.
- Undo history ends when the program exits.
- Only one copy of the program should have the list open at a time.
- Exports leave out titles without a MyAnimeList id.
- Score stars need a Nerd Font.

bool TitleHolds(const Entry& shown, const std::string& text) {
	auto words = utf8::Words(text);
	auto holds = [&words](const std::string& name) {
		std::string folded = utf8::Folded(name);
		return std::ranges::all_of(
		    words, [&folded](const auto& word) { return folded.contains(word); });
	};
	return holds(shown.title) or (not shown.english_title.empty() and holds(shown.english_title));
}

#+begin_src cpp
std::string Folded(const std::string& text) {
	std::string folded;
	auto gap = [&folded] {
		if (not folded.empty() and folded.back() != ' ')
			folded += ' ';
	};
	for (const auto& glyph : SplitGlyphs(text)) {
		std::uint32_t point = CodePoint(glyph);
		if (point == '\'' or point == '`' or point == 0x2018 or point == 0x2019)
			continue;
		// AniList writes the x of HUNTER x HUNTER as a multiplication sign.
		if (point == 0xD7) {
			gap();
			folded += "x ";
		} else if ((point < 0x80 and not std::isalnum(static_cast<unsigned char>(point))) or
		           InRanges(point, kPunctuation, std::size(kPunctuation))) {
			gap();
		} else {
			folded += Lowercase(glyph);
		}
	}
	if (not folded.empty() and folded.back() == ' ')
		folded.pop_back();
	return folded;
}

std::vector<Entry> FindTitles(const Catalogue& db, const std::string& text) {
	std::string wanted = utf8::Folded(text);
	std::vector<Entry> exact;
	std::vector<Entry> holding;
	if (wanted.empty())
		return holding;
	for (MediaType type : {MediaType::kAnime, MediaType::kManga}) {
		for (const auto& each : db.GetEntries(type)) {
			if (utf8::Folded(each.title) == wanted or utf8::Folded(each.english_title) == wanted)
				exact.push_back(each);
			else if (TitleHolds(each, text))
				holding.push_back(each);
		}
	}
	return exact.empty() ? holding : exact;
}

std::optional<int> TypoCost(const std::vector<std::string>& words, const std::string& name) {
	auto parts = utf8::Words(name);
	int total = 0;
	for (const auto& word : words) {
		int allowed = static_cast<int>(utf8::SplitGlyphs(word).size()) / 3;
		int best = allowed + 1;
		for (const auto& part : parts)
			best = std::min(best, part.contains(word) ? 0 : utf8::EditDistance(word, part));
		if (best > allowed)
			return std::nullopt;
		total += best;
	}
	return total;
}

void ShowPages(App& app, const std::string& heading, std::vector<Entry> titles, SortKey key) {
	if (titles.empty()) {
		app.out << "No titles to list.\n";
		Pause(app);
		return;
	}
	SortEntries(titles, key, false);
	std::stable_partition(titles.begin(), titles.end(),
	                      [](const Entry& e) { return e.type == MediaType::kAnime; });
	size_t pages = (titles.size() + kPageSize - 1) / kPageSize;
	size_t page = 0;
	while (true) {
		ClearScreen(app);
		DrawHeading(app, std::format("{} ({})", heading, titles.size()));
		PrintRows(app, titles, page * kPageSize, std::min(titles.size(), (page + 1) * kPageSize));
		if (pages == 1) {
			Pause(app);
			return;
		}
		app.out << std::format("\nPage {} of {}\n   1  Next page\n   2  Previous page\n   0  Back\n\n",
		                       page + 1, pages);
		switch (ReadChoice(app, 2)) {
			case 1:
				page = std::min(page + 1, pages - 1);
				break;
			case 2:
				page = page > 0 ? page - 1 : 0;
				break;
			default:
				return;
		}
	}
}

#+begin_src cpp
Entry ApplyStatusDates(Entry target, WatchStatus previous, const IsoDate& today) {
	switch (target.status) {
		case WatchStatus::kWatching:
			if (not target.start_date)
				target.start_date = today;
			target.finish_date.reset();
			break;
		case WatchStatus::kCompleted:
			if (not target.start_date)
				target.start_date = today;
			if (previous != WatchStatus::kRewatching or not target.finish_date)
				target.finish_date = today;
			if (HasKnownTotal(target))
				target.progress = std::max(target.progress, target.total_units);
			if (previous == WatchStatus::kRewatching)
				++target.rewatched;
			break;
		case WatchStatus::kOnHold:
		case WatchStatus::kDropped:
		case WatchStatus::kPlanToWatch:
			target.finish_date.reset();
			break;
		case WatchStatus::kRewatching:
			if (previous == WatchStatus::kCompleted)
				target.progress = 0;
			if (not target.start_date)
				target.start_date = today;
			break;
	}
	return target;
}

#+begin_src cpp
Entry SetStatus(Entry target, WatchStatus status, const IsoDate& today) {
	if (status == target.status)
		return target;
	WatchStatus previous = target.status;
	if (previous == WatchStatus::kRewatching) {
		if (status == WatchStatus::kWatching)
			return target;
		if (IsPaused(status)) {
			target.status = WatchStatus::kCompleted;
			if (HasKnownTotal(target))
				target.progress = target.total_units;
			target.updated_at = today;
			return target;
		}
	}
	target.status = status;
	target = ApplyStatusDates(target, previous, today);
	target.updated_at = today;
	return target;
}

std::vector<Clash> ClashesOf(const Entry& mine, const Entry& file) {
	std::vector<Clash> clashes;
	int total = file.total_units > 0 ? file.total_units : mine.total_units;
	if (mine.status != file.status)
		clashes.push_back({"status", StatusKey(mine.status), StatusKey(file.status)});
	auto count = [&](const char* field, int Entry::* value, bool out_of_total = false) {
		if (mine.*value == 0 or file.*value == 0 or mine.*value == file.*value)
			return;
		clashes.push_back({field,
		                   out_of_total ? OutOf(mine.*value, total) : std::to_string(mine.*value),
		                   out_of_total ? OutOf(file.*value, total) : std::to_string(file.*value)});
	};
	auto date = [&](const char* field, std::optional<IsoDate> Entry::* value) {
		if (mine.*value and file.*value and mine.*value != file.*value)
			clashes.push_back({field, FormatDate(mine.*value), FormatDate(file.*value)});
	};
	count("score", &Entry::score);
	count("progress", &Entry::progress, true);
	count("volumes", &Entry::volumes);
	count("rewatched", &Entry::rewatched);
	date("started", &Entry::start_date);
	date("finished", &Entry::finish_date);
	return clashes;
}

std::optional<std::set<const Entry*>> AskClashes(App& app, const std::vector<Entry>& titles) {
	std::set<const Entry*> take_file;
	std::optional<char> rest;
	for (const auto& title : titles) {
		auto mine = app.db.FindImported(title);
		auto clashes = mine ? ClashesOf(*mine, title) : std::vector<Clash>{};
		if (clashes.empty())
			continue;
		char answer = rest.value_or('\0');
		if (not rest) {
			PrintClashes(app, *mine, clashes);
			answer = AskClash(app);
		}
		if (answer == 'q')
			return std::nullopt;
		if (answer == 'K' or answer == 'F')
			rest = answer;
		if (answer == 'f' or answer == 'F')
			take_file.insert(&title);
	}
	return take_file;
}

#+begin_src cpp
bool WriteFile(const std::filesystem::path& file, const std::string& text) {
	// Written beside it and renamed, so a crash cannot leave half a file.
	auto partial = file;
	partial += ".tmp";
	std::ofstream stream(partial, std::ios::binary | std::ios::trunc);
	stream << text;
	stream.close();
	std::error_code ec;
	if (stream.good())
		std::filesystem::rename(partial, file, ec);
	if (stream.good() and not ec)
		return true;
	std::filesystem::remove(partial, ec);
	return false;
}

Result<bool> Catalogue::Load() {

	manga_.clear();
	savedAnime_.clear();
	savedManga_.clear();

	}

	savedManga_ = manga_;
	return true;

Catalist meets the CC 202 requirements as a menu-driven C++ console application with full CRUD, validated input and a clear Exit option. Its rules for status, dates and matching are covered by automated tests.

Recommended next steps are refreshing episode totals for airing shows and keeping undo history between runs.
