* Proposed Title
Catalist: A Local-First Anime and Manga Tracker for the Command Line

* Abstract
Catalist is a C++23 console application for keeping track of anime and manga. It stores a person's lists in one SQLite file on their own computer, supports creating, reading, updating and deleting titles, and can undo or redo any change. Titles are named in plain words rather than memorized codes. Catalist looks up new titles through AniList's public API without an account, and moves lists in and out as MyAnimeList XML.

* Introduction
People who follow anime and manga often track dozens or hundreds of titles at once. Catalist makes the most common action, recording one more episode or chapter, a single short command such as =catalist + frieren=.

* Background of the Program
Catalist began as the CC 202 Computer Programming 1 final project. It was simplified into a focused command-line tool after features such as account syncing, several site integrations and a full-screen interface were removed to keep it small and testable.

* Problem
Tracking sites need a browser, an account and a connection for every small update. A list kept in a text file or spreadsheet has none of those costs, but it does not know episode totals, cannot undo a mistake, and makes statistics manual work.

* Current Solution
AniList and MyAnimeList are the main tracking websites. Both keep a person's list on their servers and require an account to track titles.

* Proposed Solution
Catalist keeps the list on the person's computer and goes online only for =add= and =search=.
- Titles are named by any part of their name.
- Every change can be undone and redone.
- No account is needed.
- Lists can move to and from AniList and MyAnimeList through XML.

* Objectives
This console application aims to make tracking anime and manga fast, safe and private.

Specifically:
1. To develop a C++ console application that performs create, read, update and delete operations on anime and manga lists.
2. To implement status and date rules that keep each title's record consistent.
3. To provide undo and redo for every change.
4. To be able to find titles through AniList and exchange lists through MyAnimeList XML.

* Scope and Limitations
*Scope:* anime and manga lists, progress, scores, statuses, dates, statistics, AniList search, MyAnimeList XML import and export, and undo history.

*Limitations:*
- It runs on Linux and is built with GCC.
- =add= and =search= need an internet connection and the =curl= program.
- It does not sync with accounts on any site.
- Episode totals are not refreshed after a title is added.
- Exports leave out titles without a MyAnimeList id.
- Score stars need a Nerd Font.

#+begin_src cpp
std::string Folded(const std::string& text) {
	std::string folded;
	auto gap = [&folded] {
		if (not folded.empty() and folded.back() != ' ')
			folded += ' ';
	};
	for (const auto& glyph : SplitGlyphs(text)) {
		std::uint32_t point = CodePoint(glyph);
		if (point == '\'' or point == '`' or point == 0x2018 or point == 0x2019)
			continue;
		// AniList writes the x of HUNTER x HUNTER as a multiplication sign.
		if (point == 0xD7) {
			gap();
			folded += "x ";
		} else if ((point < 0x80 and not std::isalnum(static_cast<unsigned char>(point))) or
		           InRanges(point, kPunctuation, std::size(kPunctuation))) {
			gap();
		} else {
			folded += Lowercase(glyph);
		}
	}
	if (not folded.empty() and folded.back() == ' ')
		folded.pop_back();
	return folded;
}

std::vector<std::string> NamesIn(const std::vector<std::string>& words) {
	std::vector<std::string> names;
	std::string open;
	auto close = [&] {
		if (not open.empty())
			names.push_back(std::exchange(open, ""));
	};
	auto add = [&](const std::string& piece) {
		if (refs::Parse(piece)) {
			close();
			names.push_back(piece);
		} else if (not piece.empty()) {
			open += (open.empty() ? "" : " ") + piece;
		}
	};
	for (const auto& word : words) {
		if (word.contains(' ')) {
			close();
			names.push_back(word);
			continue;
		}
		size_t start = 0;
		for (size_t comma = word.find(','); comma != std::string::npos;
		     comma = word.find(',', start)) {
			add(word.substr(start, comma - start));
			close();
			start = comma + 1;
		}
		add(word.substr(start));
	}
	close();
	return names;
}

std::optional<int> TypoCost(const std::vector<std::string>& words, const std::string& name) {
	auto parts = utf8::Words(name);
	int total = 0;
	for (const auto& word : words) {
		int allowed = static_cast<int>(utf8::SplitGlyphs(word).size()) / 3;
		int best = allowed + 1;
		for (const auto& part : parts)
			best = std::min(best, part.contains(word) ? 0 : utf8::EditDistance(word, part));
		if (best > allowed)
			return std::nullopt;
		total += best;
	}
	return total;
}

#+begin_src cpp
bool ShowInPager(const std::string& text) {
	const char* chosen = std::getenv("PAGER");
	std::string command = chosen and *chosen ? chosen : "less";
	auto to_pager = MakePipe();
	if (not to_pager)
		return false;
	pid_t child = fork();
	if (child == 0) {
		dup2(to_pager->read.Get(), STDIN_FILENO);
		setenv("LESS", "FRX", 0);
		// main ignores SIGPIPE, and a child would inherit that.
		std::signal(SIGPIPE, SIG_DFL);
		execlp("sh", "sh", "-c", command.c_str(), nullptr);
		_exit(127);
	}
	to_pager->read.Reset();
	if (child < 0)
		return false;

	// Ctrl-C belongs to the pager; dying here would leave it on a dead terminal.
	auto previous = std::signal(SIGINT, SIG_IGN);
	size_t written = 0;
	while (written < text.size()) {
		ssize_t count = write(to_pager->write.Get(), text.data() + written, text.size() - written);
		if (count < 0 and errno == EINTR)
			continue;
		if (count <= 0)
			break;
		written += static_cast<size_t>(count);
	}
	to_pager->write.Reset();
	int status = 0;
	pid_t waited = -1;
	do {
		waited = waitpid(child, &status, 0);
	} while (waited < 0 and errno == EINTR);
	std::signal(SIGINT, previous);
	return waited == child and not(WIFEXITED(status) and WEXITSTATUS(status) == 127);
}

#+begin_src cpp
Entry ApplyStatusDates(Entry target, WatchStatus previous, const IsoDate& today) {
	switch (target.status) {
		case WatchStatus::kWatching:
			if (not target.start_date)
				target.start_date = today;
			target.finish_date.reset();
			break;
		case WatchStatus::kCompleted:
			if (not target.start_date)
				target.start_date = today;
			if (previous != WatchStatus::kRewatching or not target.finish_date)
				target.finish_date = today;
			if (HasKnownTotal(target))
				target.progress = std::max(target.progress, target.total_units);
			if (previous == WatchStatus::kRewatching)
				++target.rewatched;
			break;
		case WatchStatus::kOnHold:
		case WatchStatus::kDropped:
		case WatchStatus::kPlanToWatch:
			target.finish_date.reset();
			break;
		case WatchStatus::kRewatching:
			// Again from the start; the dates stay those of the first time.
			if (previous == WatchStatus::kCompleted)
				target.progress = 0;
			if (not target.start_date)
				target.start_date = today;
			break;
	}
	return target;
}

#+begin_src cpp
Entry SetStatus(Entry target, WatchStatus status, const IsoDate& today) {
	if (status == target.status)
		return target;
	WatchStatus previous = target.status;
	if (previous == WatchStatus::kRewatching) {
		if (status == WatchStatus::kWatching)
			return target;
		if (IsPaused(status)) {
			target.status = WatchStatus::kCompleted;
			if (HasKnownTotal(target))
				target.progress = target.total_units;
			target.updated_at = today;
			return target;
		}
	}
	target.status = status;
	target = ApplyStatusDates(target, previous, today);
	target.updated_at = today;
	return target;
}

std::vector<Clash> ClashesOf(const Entry& mine, const Entry& file) {
	std::vector<Clash> clashes;
	int total = file.total_units > 0 ? file.total_units : mine.total_units;
	if (mine.status != file.status)
		clashes.push_back({"status", StatusKey(mine.status), StatusKey(file.status)});
	auto count = [&](const char* field, int Entry::* value, bool out_of_total = false) {
		if (mine.*value == 0 or file.*value == 0 or mine.*value == file.*value)
			return;
		clashes.push_back({field,
		                   out_of_total ? OutOf(mine.*value, total) : std::to_string(mine.*value),
		                   out_of_total ? OutOf(file.*value, total) : std::to_string(file.*value)});
	};
	auto date = [&](const char* field, std::optional<IsoDate> Entry::* value) {
		if (mine.*value and file.*value and mine.*value != file.*value)
			clashes.push_back({field, FormatDate(mine.*value), FormatDate(file.*value)});
	};
	count("score", &Entry::score);
	count("progress", &Entry::progress, true);
	count("volumes", &Entry::volumes);
	count("rewatched", &Entry::rewatched);
	date("started", &Entry::start_date);
	date("finished", &Entry::finish_date);
	return clashes;
}

#+begin_src cpp
std::optional<std::set<const Entry*>> AskClashes(CliContext& ctx,
                                                 const std::vector<Source>& sources) {
	std::set<const Entry*> take_file;
	std::optional<char> rest;
	for (const auto& source : sources) {
		for (const auto& title : source.titles) {
			auto mine = ctx.db.FindImported(title);
			auto clashes = mine ? ClashesOf(*mine, title) : std::vector<Clash>{};
			if (clashes.empty())
				continue;
			char answer = rest.value_or('\0');
			if (not rest) {
				PrintClashes(ctx, *mine, clashes);
				answer = AskClash(ctx);
			}
			if (answer == 'q')
				return std::nullopt;
			if (answer == 'K' or answer == 'F')
				rest = answer;
			if (answer == 'f' or answer == 'F')
				take_file.insert(&title);
		}
	}
	return take_file;
}

#+begin_src cpp
Done BackUpStore(store::Database& db, const std::filesystem::path& file, int version) {
	auto copy = file;
	{
		// VACUUM fails while another statement is still open.
		auto now = db.Prepare("SELECT strftime('%Y%m%d-%H%M%S', 'now', 'localtime')");
		if (not now.Step())
			return std::unexpected(
			    std::format("cannot back up {}: {}", file.string(), db.LastError()));
		copy.replace_filename(std::format("catalist-v{}-{}.db", version, now.TextAt(0)));
	}
	auto vacuum = db.Prepare("VACUUM INTO ?");
	if (not vacuum.Bind(copy.string()).Run())
		return std::unexpected(std::format("cannot back up {} to {}: {}; it was not upgraded",
		                                   file.string(), copy.string(), db.LastError()));
	return Done{};
}
