* Proposed Title
Catalist: A Menu-Driven Anime and Manga Tracker

* Abstract
Catalist is a menu-driven C++23 console application for keeping track of anime and manga. Through numbered menus, a person opens their anime or manga list, searches, filters and sorts it, opens a title to update or remove it, adds new titles, and sees statistics. The lists are saved in one CSV file in the project folder. New titles are found through AniList's public API without an account, and lists can be moved in and out as MyAnimeList XML.

* Introduction
People who follow anime and manga often track dozens or hundreds of titles at once. Catalist keeps those lists in a simple console program, where the most common action, recording one more episode or chapter, takes a few number keys.

* Background of the Program
Catalist is the final project for CC 202 Computer Programming 1, which calls for a complete C++ console application with CRUD operations, decision statements, loops, input validation and a user-friendly menu with an Exit option.

* Problem
Tracking sites need a browser, an account and a connection for every small update. A list kept in a text file or spreadsheet has none of those costs, but it does not know episode totals and makes statistics manual work.

* Current Solution
AniList and MyAnimeList are the main tracking websites. Both keep a person's list on their servers and require an account to track titles.

* Proposed Solution
Catalist keeps the list in a readable CSV file on the person's computer and goes online only to add a title.
- Every action is a numbered menu choice or a one-letter key listed on screen.
- Titles are found by any part of their name, and lists can be filtered and sorted.
- Viewing and editing a title happen on one page.
- No account is needed.
- Lists can move to and from AniList and MyAnimeList through XML.

* Objectives
This console application aims to make tracking anime and manga simple and private.

Specifically:
1. To develop a menu-driven C++ console application that performs create, read, update and delete operations on anime and manga lists.
2. To implement status and date rules that keep each title's record consistent.
3. To validate all input and handle errors without losing data.
4. To be able to find titles through AniList and exchange lists through MyAnimeList XML.

* Scope and Limitations
*Scope:* anime and manga lists, progress, scores, statuses, dates, searching, filtering and sorting, statistics, AniList search and MyAnimeList XML import and export.

*Limitations:*
- It runs on Linux and is built with GCC.
- Adding a title needs an internet connection and the =curl= program.
- It does not sync with accounts on any site.
- Episode totals are not refreshed after a title is added.
- A saved change cannot be undone from the program.
- Only one copy of the program should have the list open at a time.
- Exports leave out titles without a MyAnimeList id.

int ReadChoice(App& app, int highest) {
	while (true) {
		auto answer =
		    ReadLine(app, std::format("{} Enter choice [0-{}]: ",
			                          output::Paint(">", output::kMagenta, app.color), highest));

bool TitleHolds(const Entry& shown, const std::string& text) {
	auto words = utf8::Words(text);
	auto holds = [&words](const std::string& name) {
		std::string folded = utf8::Folded(name);
		return std::ranges::all_of(words,
		                           [&folded](const auto& word) { return folded.contains(word); });
	};
	return holds(shown.title) or (not shown.english_title.empty() and holds(shown.english_title));
}

#+begin_src cpp
std::string Folded(const std::string& text) {
	std::string folded;
	auto gap = [&folded] {
		if (not folded.empty() and folded.back() != ' ')
			folded += ' ';
	};
	for (const auto& glyph : SplitGlyphs(text)) {
		std::uint32_t point = CodePoint(glyph);
		if (point == '\'' or point == '`' or point == 0x2018 or point == 0x2019)
			continue;
		// AniList writes the x of HUNTER x HUNTER as a multiplication sign.
		if (point == 0xD7) {
			gap();
			folded += "x ";
		} else if ((point < 0x80 and not std::isalnum(static_cast<unsigned char>(point))) or
		           InRanges(point, kPunctuation, std::size(kPunctuation))) {
			gap();
		} else {
			folded += Lowercase(glyph);
		}
	}
	if (not folded.empty() and folded.back() == ' ')
		folded.pop_back();
	return folded;
}
#+end_src

std::optional<int> TypoCost(const std::vector<std::string>& words, const std::string& name) {
	auto parts = utf8::Words(name);
	int total = 0;
	for (const auto& word : words) {
		int allowed = static_cast<int>(utf8::SplitGlyphs(word).size()) / 3;
		int best = allowed + 1;
		for (const auto& part : parts)
			best = std::min(best, part.contains(word) ? 0 : utf8::EditDistance(word, part));
		if (best > allowed)
			return std::nullopt;
		total += best;
	}
	return total;
}

Entry ApplyStatusDates(Entry target, WatchStatus previous, const IsoDate& today) {
	switch (target.status) {
		case WatchStatus::kWatching:
			if (not target.start_date)
				target.start_date = today;
			target.finish_date.reset();
			break;
		case WatchStatus::kCompleted:
			if (not target.start_date)
				target.start_date = today;
			if (previous != WatchStatus::kRewatching or not target.finish_date)
				target.finish_date = today;
			if (HasKnownTotal(target))
				target.progress = std::max(target.progress, target.total_units);
			if (previous == WatchStatus::kRewatching)
				++target.rewatched;
			break;
		case WatchStatus::kOnHold:
		case WatchStatus::kDropped:
		case WatchStatus::kPlanToWatch:
			target.finish_date.reset();
			break;
		case WatchStatus::kRewatching:
			if (previous == WatchStatus::kCompleted)
				target.progress = 0;
			if (not target.start_date)
				target.start_date = today;
			break;

	std::vector<Clash> clashes;

	if (mine.status != file.status)

#+begin_src cpp
bool WriteFile(const std::filesystem::path& file, const std::string& text) {
	// Written beside it and renamed, so a crash cannot leave half a file.
	auto partial = file;
	partial += ".tmp";
	std::ofstream stream(partial, std::ios::binary | std::ios::trunc);
	stream << text;
	stream.close();
	std::error_code ec;
	if (stream.good())
		std::filesystem::rename(partial, file, ec);
	if (stream.good() and not ec)
		return true;
	std::filesystem::remove(partial, ec);
	return false;
}

Result<bool> Catalogue::Load() {
	anime_.clear();
	manga_.clear();
	savedAnime_.clear();
	savedManga_.clear();
	std::error_code ignored;
	if (not std::filesystem::exists(file_, ignored))
		return false;
	auto text = ReadFile(file_);
	if (not text)
		return std::unexpected(std::format("cannot read {}", file_.string()));

	auto records = csv_codec::SplitRecords(*text);
	if (records.empty() or
	    (records[0] != csv_codec::kHeader and records[0] != csv_codec::kOldHeader))
		return std::unexpected(std::format("{} is not a Catalist list", file_.string()));
	for (size_t i = 1; i < records.size(); ++i) {
		auto row = csv_codec::DecodeEntry(csv_codec::SplitFields(records[i]));
		if (not row or FindById(GetList(row->type), row->id))
			return std::unexpected(
			    std::format("{}: row {} is damaged; fix it or restore the file", file_.string(), i));
		GetList(row->type).push_back(*row);
	}
	savedAnime_ = anime_;
	savedManga_ = manga_;
	return true;
}

** Decisions replaced along the way
These were decided during development, then replaced when the course requirement for a menu-driven program became clear.
- Commands such as =catalist + frieren= and =catalist ls=: replaced by the menus.
- Refs such as =a:12=, options, comma-separated titles, piped output and script behavior: removed with the command line.
- An external pager: replaced by numbered pages.
- SQLite storage and automatic database backups: replaced by one CSV file.
- Undo, redo and the change history: removed because they made the program too complex.
- The Continue section on the main screen: removed to keep the screen simple.
- Plain-text menus (=1. Add Title=, a bold "Catalist" heading, =[y/N]=, =[k]eep=): replaced for a time by logos, Nerd Font icons and circled hints. The import keys K and F became r and t then, and both still work.
- Nerd Font icons and circled numbers, letters and statuses: replaced by plain ASCII (2.3), so the program looks the same in any terminal and font, and in the PDF.
- The seven-item main menu (Add Title, View Lists, Log Progress, Edit Title, Remove Title, Stats, Import & Export): replaced by Anime, Manga and Import & Export (1.1). Viewing and editing were on separate screens, so a title was looked up twice; now a title opens on one page with every action (4.2).
- View Lists' In Progress, All Titles, By Status and Search Lists: replaced by typing to search, filters and six sorts on each list (3.2 to 3.5).
- Log Progress: replaced by +1 Episode on the title page (2.6).
- Asking "Did you mean ...?" with yes or no: replaced by a note under the list that names the closest title (3.3).
- Adding anime and manga in one search: Add now searches the kind of list it is on (6.1).
- A live search that filters as each key is typed, moved with Tab: considered, and turned down because a numbered menu is what the course asks for and it would need raw terminal input.
- The rewatch value (MyAnimeList's 1 to 5 scale) as a column, a card row and an Edit Title option: removed, because AniList has no such field (7.6).

* Conclusion and Recommendations
Catalist meets the CC 202 requirements as a menu-driven C++ console application with full CRUD, validated input and a clear Exit option. Its main menu has three choices, and each list keeps searching, filtering, sorting and every change to a title in one place. Its rules for status, dates and matching are covered by automated tests.

A recommended next step is refreshing episode totals for airing shows.
